One sentence, 143 characters, pitching a bizarre startup that sounds absurd
until the money clause lands: idle hearses rented out as the world's
quietest nap pods, because night-shift nurses will pay $15 for 40 minutes
of silence nobody dares interrupt.

`main.py` (Python 3.13, standard library only) writes the pitch to
`entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`), with no trailing
newline. Deterministic — the same bytes on every run.
